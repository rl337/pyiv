Bases: object

Buffered HTTP response (status, headers, body).

Why this exists: Injectable clients need a typed response object with json() / text / raise_for_status() — not a bare dict — so streaming and status handling stay natural at call sites.

Example

>>> from pyiv.http.response import HttpResponse
>>> r = HttpResponse(200, {"Content-Type": "application/json"}, b'{"a": 1}', "http://x/")
>>> r.json()
{'a': 1}
>>> r.raise_for_status()
