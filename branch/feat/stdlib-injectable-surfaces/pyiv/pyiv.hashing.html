class pyiv.hashing.Hasher[source]

Bases: ABC

Injectable digest / HMAC helper.

Why this exists: Call sites that hard-code hashlib are harder to stub for fixed digests in tests.

Example

>>> from pyiv.hashing import RealHasher
>>> h: Hasher = RealHasher()
>>> h.digest("sha256", b"abc").hex()[:8]
'ba7816bf'

Why this exists: Assert hashing call shapes without real crypto cost.

Example

>>> h = SyntheticHasher(fixed=b"\x00\x01")
>>> h.digest("sha256", b"x")
