class pyiv.http.base.AsyncHttpClient[source]

Bases: ABC

Async injectable HTTP client.

Why this exists: Async apps (inference adapters, SSE) need the same injectable contract as sync code without requiring httpx in core. Bind AsyncUrllibHttpClient or MemoryAsyncHttpClient.

Example

>>> import asyncio
>>> from pyiv.http import MemoryAsyncHttpClient
>>> async def _demo():
...     client = MemoryAsyncHttpClient()
...     client.add("GET", "http://example.test/", body=b"hi")
...     r = await client.get("http://example.test/")
...     return r.text
>>> asyncio.run(_demo())
'hi'

class pyiv.http.base.HttpClient[source]

Bases: ABC

Sync injectable HTTP client.

Why this exists: Apps should depend on a typed client (JSON bodies, status handling, optional streaming) instead of hard-coding urllib or a third-party stack. Bind UrllibHttpClient in production and MemoryHttpClient in tests.

Example

>>> from pyiv.http import HttpResponse, MemoryHttpClient
>>> client: HttpClient = MemoryHttpClient()
>>> client.add("GET", "http://example.test/x", body=b"ok")
>>> client.get("http://example.test/x").text
'ok'
