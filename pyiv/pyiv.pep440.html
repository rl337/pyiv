pyiv.pep440

Public PEP 440 version parsing and specifier matching.

This module is the stdlib-only PEP 440 engine used by Pep440VersionParser (registered under the name "PEP440" on Config). Semantics follow PEP 440 (release ordering, prereleases, ~=, comma-combined specifiers). Prereleases are excluded from matching unless the specifier itself names a prerelease (same default as packaging).

Why this exists: Package and interpreter version domains need a real PEP 440 matcher without a third-party runtime dependency. Hosts and tests can import Version / SpecifierSet directly, or use the VersionParser façade Pep440VersionParser.

Example

>>> from pyiv.pep440 import SpecifierSet, Version
>>> Version("1.0") < Version("1.1")
True
>>> SpecifierSet(">=2.30,<3").contains("2.31.0")
True

class pyiv.pep440.Pep440VersionParser[source]

Bases: object

VersionParser implementation for PEP 440.

Why this exists: Python package and interpreter domains need a named, standards-based parser. Config registers this under pyiv.version.PEP440 by default so for_package_version / for_python_version work without extra setup. Presence / absence (for_package_present / for_package_absent) do not use this parser — they short-circuit on PACKAGE_PRESENT / PACKAGE_ABSENT.

Example

>>> from pyiv.pep440 import Pep440VersionParser
>>> p = Pep440VersionParser()
>>> p.is_version_compatible("3.11.5", ">=3.11,<3.12")
True
>>> p.is_version_less("3.10", "3.11")
True
>>> p.is_version_greater("2.0", "1.0")
True
