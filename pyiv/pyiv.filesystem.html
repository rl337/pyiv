pyiv.filesystem

Filesystem abstraction for dependency injection.

This module provides abstract interfaces and implementations for file system operations, enabling dependency injection of file I/O for easier testing and platform abstraction.

Architecture:

  • Filesystem: Abstract base class defining file operations

  • RealFilesystem: Production implementation using Python’s pathlib/os

  • MemoryFilesystem: Test implementation with in-memory file storage

Usage:

For production code, use RealFilesystem which performs actual file operations. For testing, use MemoryFilesystem which stores files in memory without touching the disk.

Example:
>>> from pyiv.filesystem import MemoryFilesystem
>>> fs = MemoryFilesystem()
>>> fs.write_text("test.txt", "test content")
>>> fs.read_text("test.txt")
'test content'
