pyiv.reflection

Reflection-based discovery for dependency injection.

This module provides functionality to automatically discover interface implementations in Python packages using reflection, eliminating the need for manual registration.

What Problem Does This Solve?

Plugin-style packages accumulate many implementations. Hand-registering each class is brittle; scanning a package once keeps discovery in DI. For catalogs (recipes, tools, handlers), opt into as_multibind so every discovered class joins a map/set/list multibind instead of last-wins unqualified register.

Real-World Use Cases: - Scan myapp.handlers for *Handler classes - Fill a recipe catalog via as_multibind="map" and key_attr="name" - Accumulate list/set multibinds across install of several packages

Architecture:

  • ReflectionConfig: Config subclass with register_module discovery

  • Legacy path: each discovery calls register (last implementation wins)

  • Catalog path: as_multibind contributes to map/set/list multibinds

Usage Examples:

Scan A Package Into A Map Catalog:

>>> import sys, types
>>> from pyiv import get_injector
>>> from pyiv.reflection import ReflectionConfig
>>> class Recipe:
...     name = "base"
>>> pkg = types.ModuleType("doctest_catalog_recipes")
>>> class HarnessRun(Recipe):
...     name = "harness_run"
>>> class VerifyRepair(Recipe):
...     name = "verify_repair"
>>> HarnessRun.__module__ = "doctest_catalog_recipes"
>>> VerifyRepair.__module__ = "doctest_catalog_recipes"
>>> pkg.HarnessRun = HarnessRun
>>> pkg.VerifyRepair = VerifyRepair
>>> sys.modules["doctest_catalog_recipes"] = pkg
>>> class RecipeConfig(ReflectionConfig):
...     def configure(self):
...         self.register_module(
...             Recipe,
...             "doctest_catalog_recipes",
...             as_multibind="map",
...             key_attr="name",
...             recursive=False,
...         )
>>> sorted(get_injector(RecipeConfig).catalog_keys(Recipe))
['harness_run', 'verify_repair']

Bases: Config

Configuration that discovers implementations in packages via reflection.

Why this exists: Auto-discover interface implementations in a package instead of listing every class. Use as_multibind when discoveries must accumulate into a catalog (map/set/list) rather than overwrite a single unqualified binding.

Example

>>> import sys, types
>>> from pyiv import get_injector
>>> from pyiv.reflection import ReflectionConfig
>>> class Tool:
...     name = "base"
>>> pkg = types.ModuleType("doctest_tools_pkg")
>>> class GrepTool(Tool):
...     name = "grep"
>>> class LintTool(Tool):
...     name = "lint"
>>> GrepTool.__module__ = "doctest_tools_pkg"
>>> LintTool.__module__ = "doctest_tools_pkg"
>>> pkg.GrepTool = GrepTool
>>> pkg.LintTool = LintTool
>>> sys.modules["doctest_tools_pkg"] = pkg
>>> class ToolConfig(ReflectionConfig):
...     def configure(self):
...         self.register_module(
...             Tool,
...             "doctest_tools_pkg",
...             pattern="*Tool",
...             as_multibind="map",
...             key_attr="name",
...             recursive=False,
...         )
>>> get_injector(ToolConfig).catalog_keys(Tool)
['grep', 'lint']

discover_implementations(interface: Type) → Dict[str, Type][source]

Discover all implementations of an interface in registered modules.

This method scans the registered package for classes that implement the given interface. Only classes within the specified package (and optionally submodules) are discovered - no discovery happens outside the registered package boundaries.

Parameters:

interface – The interface to discover implementations for

Returns:

Dictionary mapping implementation names to classes. Keys are class names (or “submodule.ClassName” for submodules).

Raises:

  • ValueError – If no module registration exists for the interface

  • ImportError – If the package cannot be imported

register_module(interface: Type, package_path: str, pattern: str | None = None, recursive: bool = True, singleton_type: SingletonType = SingletonType.SINGLETON, *, as_multibind: Literal['map', 'set', 'list'] | None = None, key_attr: str | None = None, on_conflict: Literal['replace', 'error', 'keep'] = 'error')[source]

Register a package to scan for interface implementations.

Parameters:

  • interface – The abstract class or interface to find implementations of

  • package_path – Python package path (e.g., “my_service.mcp.handlers”)

  • pattern – Optional name pattern for filtering (e.g. *Handler, handle_*). Uses fnmatch syntax. If None, all implementations are discovered.

  • recursive – Whether to scan submodules recursively (default: True)

  • singleton_type – How to handle instances on the legacy unqualified register path (ignored when as_multibind is set)

  • as_multibind – If None (default), each discovery calls register(interface, impl) (last wins). If "map", "set", or "list", discoveries join that multibind only and do not overwrite the unqualified binding.

  • key_attr – Class attribute name used as the map key when as_multibind="map" (required in that mode)

  • on_conflict – Conflict policy for map multibind contributions (default "error" so duplicate catalog ids fail loudly)

Raises:

  • TypeError – If interface is not a type

  • ImportError – If the package cannot be imported

  • ValueError – If map mode lacks key_attr or a class lacks the attr

Example

>>> import sys, types
>>> from pyiv.reflection import ReflectionConfig
>>> class Handler:
...     pass
>>> pkg = types.ModuleType("doctest_handler_list")
>>> class CreateHandler(Handler):
...     pass
>>> class UpdateHandler(Handler):
...     pass
>>> CreateHandler.__module__ = "doctest_handler_list"
>>> UpdateHandler.__module__ = "doctest_handler_list"
>>> pkg.CreateHandler = CreateHandler
>>> pkg.UpdateHandler = UpdateHandler
>>> sys.modules["doctest_handler_list"] = pkg
>>> class ListConfig(ReflectionConfig):
...     def configure(self):
...         self.register_module(
...             Handler,
...             "doctest_handler_list",
...             pattern="*Handler",
...             as_multibind="list",
...             recursive=False,
...         )
>>> mb = ListConfig().get_multibinding(Handler)
>>> sorted(c.__name__ for c in mb[1])
['CreateHandler', 'UpdateHandler']
